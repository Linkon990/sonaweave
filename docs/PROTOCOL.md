# SonaWeave 协议说明

0.2.2 默认主页面使用下述 SWP-1 FSK / DTMF，副页面使用 ggwave，详见 [GGWAVE.md](GGWAVE.md)。两者分别使用自己的帧与纠错方式，不能把 SWP-1 的 CRC16/Hamming 指标用于 ggwave。

## 旧版 SWP-1

SWP-1 是 SonaWeave 的演示帧格式。所有多字节整数均使用网络字节序（big-endian）。

## 发送链路

1. 使用 `TextEncoder` 把文本转换为 UTF-8 字节。
2. 生成固定 12-bit 码字的 LZW 候选载荷；仅当候选严格小于原始字节时才采用。
3. 写入 SWP-1 头部和 CRC16-CCITT。
4. 每个帧字节拆成两个 4-bit 半字节，分别编码为 Hamming(8,4) SECDED 码字。
5. 使用 FSK 的 0/1 比特或 DTMF 的 0..F 符号生成 48 kHz PCM 音频。

## 帧布局

| Offset | Length | Field | Description |
|---:|---:|---|---|
| 0 | 2 | Magic | ASCII `SW`，即 `0x53 0x57` |
| 2 | 1 | Version | 当前为 `0x01` |
| 3 | 1 | Flags | bit 0 表示载荷使用 LZW12 |
| 4 | 2 | Message ID | 发送端生成的 16-bit 消息号 |
| 6 | 2 | Original length | 解压后的 UTF-8 字节数 |
| 8 | 2 | Payload length | 帧内载荷字节数 |
| 10 | N | Payload | 原始 UTF-8 或 LZW12 数据 |
| 10+N | 2 | CRC16 | 对头部和载荷计算 CRC16-CCITT |

## LZW12

- 初始字典包含全部 0..255 单字节值。
- 动态字典码从 256 开始，最大码值为 4095。
- 码字固定占 12 bit，以 MSB-first 连续打包。
- 压缩载荷前两个字节保存码字数量，用于排除末尾补齐位。
- 字典满后停止新增条目，不做隐式重置，因此编解码结果确定。
- 接收解压前必须通过帧 CRC；展开时以帧声明的 `Original length` 为硬上限，在追加输出或增长字典前检查，避免先生成过大的结果再检查长度。独立 `decompressLzw` 默认上限为 SWP-1 的 65,535 字节。

## Hamming(8,4) SECDED

数据位放在位置 3、5、6、7，Hamming 校验位放在 1、2、4，位置 8 保存整体彩 parity。接收端根据三位 syndrome 和整体奇偶性区分：

- syndrome = 0、overall = 0：无错误。
- syndrome != 0、overall = 1：1..7 中存在单比特错误，可定位并纠正。
- syndrome = 0、overall = 1：整体校验位错误，可纠正。
- syndrome != 0、overall = 0：至少双比特错误，只检测不误纠正。

每 4 bit 变为 8 bit，因此纠错编码会让帧长度翻倍。CRC16 在纠错之后再次判断整帧是否可信。

## FSK 参数

| Parameter | Value |
|---|---:|
| Sample rate | 48,000 Hz |
| Baud rate | 600 symbols/s |
| Samples/symbol | 80 |
| Bit 0 | 1,800 Hz |
| Bit 1 | 3,000 Hz |
| Preamble | 32 个交替 0/1 |
| Sync word | `0xD391` |

接收端在整段录音上计算两个目标频率的滑动正交相关能量，再滑动匹配全部 48 个训练比特。没有只锁定第一个响声的能量起点门限，因此录音开始后的说话声、提示音或较早的损坏载波不会直接屏蔽后面的有效载波。满足训练一致性门限的多个候选按时间顺序验证；粗时间网格命中后逐采样细化训练边界。

接收码元周期保留为 `sampleRate / 600` 的浮点数，例如 44.1 kHz 下是 73.5 个采样，而不是逐码元取整为 74。解调时在预测边界附近跟踪既有 FSK 波形淡入淡出的能量谷值，避免小幅播放/采集时钟偏差随长消息累积。频率、600 baud、训练序列和发送波形均保持兼容。

## DTMF 参数

使用四个低频行 `[697, 770, 852, 941]` 和四个高频列 `[1209, 1336, 1477, 1633]` 组成 16 个符号。每个符号直接表示一个半字节。

| Parameter | Value |
|---|---:|
| Tone | 36 ms |
| Gap | 6 ms |
| Training symbols | `A 5 A 5 D E A D` |

接收端分别计算四个行频率和四个列频率的能量，选择能量最大的行列交点作为符号。它和 Goertzel 检测使用同一个原则：只测少数已知频率，而不是计算完整 FFT。

DTMF 同样搜索整段录音中的多个训练序列候选，并保留浮点周期 `sampleRate * 0.042`。局部时序跟踪利用原有 6 ms 间隔内的能量谷值。同步搜索的滑动相关计算随录音长度线性增长，相关能量只保留在稀疏时间网格上；不会为每一个候选重新计算整段频谱。候选先只读取并恢复 10 字节头部，再按头部指定长度读取有效帧，避免把剩余录音全部当作载荷解调。

## 接收校验与自动识别

- `decodeSamples(samples, sampleRate, mode)` 保留指定模式的 API。一个候选头部无效、帧不完整或 CRC 不通过时，会继续尝试后面的训练候选。
- `decodeSamplesAuto(samples, sampleRate, preferred = "fsk")` 先试首选模式，再试另一模式；成功报告的 `mode` 给出实际识别结果。首选模式不需要与发送端一致。
- 成功必须经过合法 SWP-1 头部、Hamming 恢复、完整帧 CRC16、可选解压长度和严格 UTF-8 校验。头部或有效帧内任何被 SECDED 明确标记为不可纠正的码字都必须拒收，即使 CRC 恰好一致；CRC16 存在碰撞，不能覆盖已知的 FEC 错误。训练得分或载波能量本身都不代表解码成功。
- 空录音、近乎静音、非法采样值/采样率和没有匹配训练序列的录音会明确拒绝。支持的输入采样率范围为 8–192 kHz；固定回归覆盖 16、44.1 和 48 kHz。
- 固定输入回归覆盖任意录音窗口相位、前置无关响声、较早帧 CRC 损坏后的回退、两模式自动识别、安静小增益录音、有限噪声/回声，以及两模式 ±0.3% 的采样时钟偏差。时钟偏差回归包含 UI 上限 480 UTF-8 字节的 FSK 帧和 96 字节的 DTMF 帧；另有确定的 CRC16 碰撞加双比特 FEC 拒收和 LZW 展开限额回归。

局部能量边界跟踪针对现有 SWP-1 的淡入淡出和音调间隔，并不等于通用连续时钟恢复。强混响、硬件降噪抹去波形包络、严重削波、频响缺口或训练序列被截断仍可能导致失败；以上数字回归不能代替两台实体设备之间的空气链路成功率实测。

## 信道模型

实验台按固定随机种子生成结果，便于复现：

- AWGN：由信号 RMS 和目标 SNR 推导噪声 RMS。
- 突发衰落：以 12 ms 为块随机衰减最多 94%。
- 回声：叠加延迟 7 ms 的原信号副本。

这个模型用于相对比较，不等价于真实房间脉冲响应或标准无线衰落模型。


## 0.2.0 兼容接收修复

每个训练起点先尝试原包络跟踪；候选失败后尝试固定分数符号周期，不再强迫所有输入跟随滤波或回声偏移后的能量谷。两种候选都必须通过同样完整头部、FEC、CRC、解压长度和 UTF-8 校验。保留原跟踪以兼容长消息时钟漂移。4 项固定滤波/早期回声/多径回归锁定此行为；另存的 11 份相同 PCM 在修前均失败、修后均恢复。它们是确定性数字声道，不是用户房间的测量。
